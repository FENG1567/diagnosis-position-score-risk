# Code availability

The analysis code and aggregate reproduction materials are publicly available at https://github.com/FENG1567/diagnosis-position-score-risk (version v1.0.0). Original code is licensed under the MIT License, and author-created aggregate results and documentation under CC BY 4.0; third-party materials retain their original licenses. The repository includes frozen aggregate inputs, scripts to rebuild the tables and figures, software tests, and instructions for reanalysis with authorized source-data access. Patient-level records are not redistributed. Reanalysis from those records requires access from the respective data custodians.
