# v3 score–risk migration validation: protocol proposal

**Status:** executable eligibility design prepared; no prediction model fitted. Root protocol approval is required before fitting. Scientific scope remains owned by ARS; quantitative implementation follows the clinical logistic-regression workflow.

## Question and target

For the prespecified sepsis/qSOFA and pneumonia/CURB-65 cohorts in eICU and MIMIC-IV, assess whether a two-parameter score-to-in-hospital-death risk map trained among primary-diagnosis records transports to a common broader test cohort, and whether an independent intercept recalibration improves held-out calibration and prediction loss. This is a revision-period exploratory migration evaluation, not an untouched external validation; prior aggregate results from these sources have already been inspected.

The analysis unit and target are hospital-admission records. Repeated admissions remain separately weighted records; patient clustering is used for uncertainty. Diagnosis position is used only to select the primary-only training set and define retrospective test subgroups. It is never a prediction input. A final analytic record must have a nonmissing patient ID, admission ID, known primary/never-primary group, binary outcome, and complete integer score in its prespecified range. The panel audit asserts one row per admission/disease and valid nonmissing outcome/group/score values; aggregate failure counts are reported. Legitimate repeated admissions remain in the analysis.

## Frozen roles and splits

Seed `JCE-v3-20261113` is frozen before event counts. Assignments use full SHA-256 integer modulo 100; no outcome, fitted estimate, or performance result determines a split. Records without a patient ID are excluded before role counts and fitting, and counted separately.

- **eICU:** hash each hospital ID to buckets 0–59 train, 60–79 recalibration, and 80–99 test. Apply this to the full panel before selecting diseases or complete cases. Exclude a patient globally if records span role buckets, if any panel row has an unassignable hospital, or if that patient appears at more than one hospital in the supplied panel. This leaves hospital roles and patient clusters disjoint. The exclusion claim is limited to multihospital patients observed in this panel.
- **MIMIC-IV temporal branch:** do not treat `anchor_year_group` itself as an admission period. For each row derive its possible calendar-year interval as `[anchor-group low + (admittime year − anchor_year), anchor-group high + (admittime year − anchor_year)]`. Use fixed windows: entire interval through 2013 = train; 2014–2016 = recalibration; 2017–2022 = test. Exclude records whose whole possible interval does not fit exactly one window. Exclude all rows for patients with records in multiple assigned roles. This branch is allowed only when the required metadata fields exist and all observed anchor-group ranges are parseable and nonoverlapping. If metadata cannot support this interval construction, use the prespecified patient hash split (same 60/20/20 buckets); do not switch to that split because event counts or model results are unfavorable. A valid temporal split that fails an eligibility gate stops without a patient-split rescue.
- All role assignment and patient exclusions occur on the whole panel before disease, group, outcome, score-completeness, or admission-ID filtering. Rows without a patient ID are excluded before role counts; rows without an admission ID are counted in flow but excluded from the final model cohorts. The final feasibility gates use only records with both identifiers. The supplied eligibility script writes aggregate counts only; no patient, admission, or hospital identifiers are written.

## Models and comparisons

Within each database and disease, fit two logistic score maps on the train role using maximum likelihood:

\[
\operatorname{logit}\{P(Y_i=1\mid S_i=s)\}=\beta_0+\beta_1s,
\]

where `Y` is in-hospital death and `S` is the integer score. The **primary-only map** uses train records with `grp=primary`; the **broad map** uses train records with either known group (primary plus never-primary). Both maps use only the score, with no variable selection, transformations, interactions, or tuning.

Apply both frozen maps to the exact same complete-case broad test cohort (`grp=primary` plus `grp=never-primary`) and report overall and group-specific results. Recalibrate each map on the same broad recalibration cohort using an offset-only logistic model, `logit(P(Y=1)) = δ + η_fixed`, fixing the original map slope at one. Test-set calibration diagnostics are point estimates only and never alter predictions: calibration-in-the-large is the intercept from `Y ~ 1 + offset(η_test)` with slope fixed at one; calibration slope is from the separate diagnostic `Y ~ 1 + η_test`. No two-parameter recalibration is planned: with a linear score map it remains in the same logistic-linear score family and adds no distinct comparison. Report training score support and test records outside that support for each map; keep those test rows and label their predictions as extrapolation.

## Outcomes and uncertainty

Report record-weighted Brier score (primary loss), stable log loss `mean(logaddexp(0, η) − Yη)` (secondary loss), calibration-in-the-large, calibration slope, ROC AUC (descriptive), and an observed-versus-predicted table by integer score. Use a numerically stable expit for probabilities. Report fixed and recalibrated maps; report test overall and primary/never-primary subgroup metrics, including distinct event- and nonevent-patient counts. Subgroup losses and score-specific observed-versus-predicted risks show residual group miscalibration after the global recalibration. AUC is descriptive only; when both score slopes are positive, the maps share the same ranking. A score-stratum residual difference under one fixed map is algebraically the existing observed risk difference, so it is not presented as a new estimand. No decision-curve analysis is planned because no clinical action threshold is specified. Calibration results are descriptive; no universal calibration pass/fail cutoff is imposed.

Use 2,000 patient-cluster bootstrap resamples of the final test cohort. Each draw samples patients with replacement and carries all their records; use the same patient multiplicities for the primary-only and broad maps and their recalibrated versions. Recompute record-weighted mean losses and paired loss differences within each draw; report percentile 95% intervals. Define paired contrasts as primary-only minus broad loss (positive favors broad training), and recalibrated minus fixed loss for each map (negative means lower recalibrated loss). These exploratory intervals are pointwise; no familywise efficacy claim or p-value selection is planned. Derive a fixed RNG seed from `JCE-v3-20261113|bootstrap|<database>|<disease>|patient`; share each draw across all maps. This conditions on fitted maps and recalibration estimates: it quantifies test-patient sampling uncertainty, not training/recalibration uncertainty. For eICU, the main patient bootstrap is also conditional on the selected held-out hospitals. If at least 20 distinct held-out hospitals remain, run a fixed secondary hospital-cluster bootstrap for paired loss differences, resampling hospitals with replacement, carrying every record in each sampled hospital, sharing draws across maps, and recomputing the record-weighted ratio. Use seed `JCE-v3-20261113|bootstrap|eICU|<disease>|hospital`. If fewer than 20 hospitals remain, report the sensitivity as unavailable. All multihospital patients observed in the panel are already excluded. This is a hospital-variation sensitivity, not a general validity proof for arbitrary hospital populations.

## Feasibility gates and stopping rules

These are operational feasibility rules, not universal calibration standards. Counts are evaluated after the frozen split and before any fitting.

- For each database/disease, both train arms (primary-only and broad) require at least 50 events, 50 nonevents, and 200 patients. Report distinct event-patient and nonevent-patient counts as dependence diagnostics. If an arm fails, stop that source/disease map comparison.
- The broad recalibration and broad test cohorts each require at least 100 events, 100 nonevents, and 200 patients. If either fails, stop that source/disease comparison; do not change the split.
- Test subgroup interval/calibration estimates require at least 200 patients, 20 events, and 20 nonevents. Below any threshold, show counts and point estimates only for that subgroup; do not report subgroup intervals or fitted calibration diagnostics.
- Do not fit or report a map that is nonfinite or fails to converge. If complete/quasi-complete separation is detected, stop that map pending a separately approved estimator; no silent Firth fallback. Test calibration diagnostics are not estimable with a nonfinite/constant linear predictor or separation; retain fixed/intercept-only results when otherwise eligible.
- Withhold a bootstrap interval if fewer than 95% of 2,000 replicates yield the prespecified metric. Record the failure count and reason; do not replace failed replicates with fresh draws. Brier/log-loss remain defined for any nonempty bootstrap draw with finite fixed predictions, including one-outcome draws. No outcome-guided split, model, subgroup, or metric selection is allowed.
